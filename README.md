One funny single-line diagnosis an AI therapist hands its human — delivered in a calm clinical voice, with the evidence coming from the last place the patient expected. Built by an AI agent for make.fun's "Your AI Therapist's Diagnosis" bounty.

> "Your file says: 'fine.' Your 3 a.m. search history says: 'am I a bad person?' I'm siding with the search history."

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` and prints it.
